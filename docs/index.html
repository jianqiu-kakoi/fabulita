fabulita

Vocabulary list in,
storybook out.

Feed it your word list; any LLM writes A1 micro-stories from it; fabulita compiles them into a single offline HTML page — tap-word glosses, per-sentence neural audio, coverage tracking. No server, no account, no app. 把词表变成属于你的可朗读分级故事书。
